# Archive Station 1.0.1-1

This maintenance release prepares Archive Station for alternative DSM package distributions. The standalone package keeps its existing identity, settings and downloads.

- Package distributors can configure the service account and DSM notification namespace without modifying application code or translations.
- The DSM gateway URL follows the application's installed URL.
- Distributions managed by Package Center can disable GitHub update checks and hide the related controls. Saved preferences and cached standalone release results cannot override this policy.
- A shared staging command builds both editions from identical application sources and language catalogs.

The SynoCommunity package remains a separate integration under review. This release does not automatically migrate between the standalone and community package identities.

# Archive Station 0.2.0-9

Community preview of **Internet Archive Downloader for Synology DSM**.

Paste Internet Archive item URLs and download their public files into a separate
folder per item, directly from a window inside DSM. No Docker or extra sign-in is required.

## Highlights

- Live transfers and upcoming files, completed-file views and an expandable folder tree.
- Pause, resume, cancel, retries, task priorities and bulk actions.
- Per-archive **⋯** menu, File Station shortcut, source link and readable download reports.
- Resumable partial files, SHA-1/MD5 verification, repair and source-list refresh.
- Live connection/rate limits, scheduling, disk reserve and DSM notifications.
- Persistent throughput graph with 1, 6, 12 and 24-hour views, remaining-time estimates and downloaded/total sizes.
- 27 interface languages; plain-text reports in English and French.

## New in this build

- Centered close icons with circular hover backgrounds throughout the application.
- The report opens at its heading without highlighting the close button. Keyboard
  focus remains visible with consistent, slimmer markers; dialog containers no
  longer display a native focus outline.
- The transfer-history period selector stays stable during settings polling.
  Its labels update only when the interface language changes, keeping the chosen period.

## Also included

- Optional daily GitHub release checks in Settings, a manual **Check now** button,
  and an option to include prereleases. A new version appears as a link above the
  download list. Checks are off by default; installation remains manual in DSM.
- Checks run independently of downloads and do not delay shutdown. Private repositories,
  missing releases and network failures are distinguished from an up-to-date package.
- The installed DSM build number is shown and used for version comparison.
- `make release` validates a committed snapshot and prepares the package, sources,
  checksums, release notes and GitHub publication instructions.

## Install or upgrade

Download **ArchiveStation-0.2.0-9-x86_64.spk** from the release assets, then select
**Package Center → Manual Install** in DSM. See the attached `INSTALL.md` for destination
permissions, checksums and upgrades. The source archive is for development, not installation.

## Compatibility and limits

- Targets DSM 7 on x86_64. Hardware testing: **DS918+, DSM 7.1.1**.
- Package upgrades and resumption were verified with an active download. Other models,
  later DSM versions and a fresh uninstall/reinstall cycle still need community testing.
- Requires a DSM administrator session. The internal loopback API assumes trusted local
  NAS accounts and services; it does not isolate the app from untrusted local workloads.
- Public Archive.org item files only: no restricted-file sign-in, recursive collection
  crawling, archive extraction or ARM package.

Please report issues with the package version, DSM version, NAS model and reproduction
steps. Remove personal paths and credentials from logs before attaching them.

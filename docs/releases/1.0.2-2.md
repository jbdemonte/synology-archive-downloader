# Archive Station 1.0.2-2

This maintenance release improves automatic reuse of an existing DSM administrator session. No additional Archive Station password is required.

## Fixes

- Recover missing or outdated DSM session tokens through DSM's same-origin session endpoint, then retry the rejected request once. Concurrent requests share recovery; tokens stay in memory and are never placed in URLs.
- Bound session recovery to five seconds, respect cancellation, and reject redirects. Failed or ambiguous download actions are not automatically repeated.
- Distinguish an unavailable DSM authentication helper from an expired session. The new diagnostic is translated into all 27 interface languages.
- Try DSM's canonical authentication executable if its documented alias is absent. Session and administrator checks remain mandatory.

## Install or upgrade

Download **ArchiveStation-1.0.2-2-x86_64.spk** below and select it in **DSM Package Center → Manual Install**. Install over the existing standalone package; do not uninstall first. Close and reopen Archive Station afterward to load the updated interface.

The release targets **DSM 7 on x86_64**. Task state, settings and downloaded files are preserved during an upgrade. The SynoCommunity recipe remains a separate contribution under review.

## Validation and compatibility

- Automated checks cover backend behavior, both DSM package identities, missing and stale tokens, shared recovery, cancellation, bounded retries and denied sessions.
- The same authentication changes were installed as test build 1.0.2-1 on a **DS918+ running DSM 7.1.1**. Existing task records, settings and sampled files were preserved, and a new Internet Archive transfer progressed with checksum verification enabled.
- This addresses a possible cause of the session error reported on **DSM 7.4.1-90080**. That DSM version has **not** been hardware-tested; confirmation from affected users is still needed.

The public package uses build revision 2 to distinguish it from the earlier local test package.

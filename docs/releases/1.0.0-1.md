# Archive Station 1.0.0-1

**Archive Station 1.0.0 — Internet Archive Downloader for Synology DSM.**

Download the public files of Internet Archive items directly to your NAS, from a
window inside DSM. Paste one or more Archive.org URLs: each item gets its own folder,
with its original subfolders preserved.

**No Docker. No additional sign-in. Downloads continue when you close the window.**

## Install

1. Download **`ArchiveStation-1.0.0-1-x86_64.spk`** from the release assets.
2. In DSM, open **Package Center → Manual Install** and select the package.
3. Launch **Archive Station**, then choose your destination in **Settings**.

See the attached `INSTALL.md` for folder permissions, checksum verification and
upgrades. The source archive is for developers; it is not needed to install the app.
The `-1` suffix identifies the first DSM package build of version 1.0.0.

## Features

- Multiple URLs, file selection and a clear folder hierarchy.
- Live transfers and upcoming files, with separate views for completed files.
- Pause, resume, cancel, retry, priorities and scheduled downloads.
- Resumable partial downloads and SHA-1/MD5 verification when Archive.org provides checksums.
- Live transfer limits, disk-space reserve and remaining-time estimates.
- Persistent transfer history with 1, 6, 12 and 24-hour views.
- 27 interface languages and readable download reports in English or French.
- File Station shortcuts, source links and DSM desktop notifications.
- Optional update notifications from GitHub Releases.

## Compatibility

- **Synology DSM 7 on x86_64**. Hardware testing to date: **DS918+, DSM 7.1.1**.
- Development builds were tested through upgrades with active downloads. This
  release packages the same download engine; the 1.0.0-1 package has not yet been
  installed on hardware. Other NAS models and DSM versions still need testing.
- Requires a DSM administrator session and trusted local NAS accounts and services.
- Public Archive.org item files only. No ARM package, restricted-file sign-in,
  recursive collection crawling or archive extraction.

## Upgrade from a development build

Install this package over the existing version through **Manual Install**. Settings,
queued tasks, completed files and resumable partial downloads are retained. Running
tasks resume; manually paused tasks stay paused. Close and reopen the application
after upgrading, and check that progress continues.

Version 1.0.0 introduces no download-state migration or change to file ownership.
